# 成长看板 · 5 个可导入示例包

一套「拿来就能体会价值」的演示数据。每个文件都是一份**完整备份 JSON**，导入即把整个看板替换成对应场景的真实排布。

## 如何使用
打开 daily-board（双击 `index.html`，或鸿蒙 NEXT 原生 App）→ 底部「**数据**」面板 →「**导入备份**」→ 选择下面的 JSON 文件。导入是整份替换，五个示例互不干扰，逐个导入体验即可。

| 文件 | 场景 | 看点 |
|---|---|---|
| `junior-demo.json` | 初中课程学习及假期安排 | 上学日 / 周末弹性双作息，7 科带章节进度 |
| `uni-demo.json` | 大学课程学习 | 上课·图书馆·健身·社团·科研·论文多线程 |
| `civil-demo.json` | 上班族考公日程 | 通勤碎片 + 晚间整块 + 周末模考的在职节奏 |
| `kaoyan-focus-demo.json` | 专心考研备考（强化阶段） | 全天深耕作息，周日模考，4 科强化进度 |
| `travel-chengdu-demo.json` | 成都周边旅游行程 | 4 条一日游 + 3 条多日游，进「旅游行程」模块 |

## 每个示例的设计要点

**示例一 · 初中**：周一~周五上学作息（晨读英语→在校课程→作业错题→兴趣阅读），周末切弹性放松（兴趣班/运动/家庭纪录片）。7 个科目填了真实章节里程碑——数学按人教版八下推进到「勾股定理」、物理到「力与运动」、化学入门等；倒计时挂「中考」「八年级期末考」。

**示例二 · 大学**：把「没有统一课表」的大学生活排进时间轴——专业课/实验占白天，晚上自习刷四六级，健身穿插，周末整块时间啃硬课 + 科研助手 + 周复盘。7 科覆盖专业核心、高数线代、英语、健身、社团、实习、论文。

**示例三 · 上班族考公**：核心是「挤时间」——通勤碎片听时政、午休保命、晚间 2 小时整块刷行测、每周三/五写申论小题、周末整套模考。4 科（行测/申论/时政/公文），倒计时挂「省考」「国考」，真实还原在职备考的节奏。

**示例四 · 专心考研**：强化阶段全天深耕——数学 3h + 专业课 3h + 政治 1h + 英语，周日整套模考订正。4 科带「强化阶段进度」里程碑（已刷题的章 done、待推进的 false），倒计时「考研初试」「考研报名」，打开「学习进度/周对比」立刻有货。

**示例五 · 成都周边旅游**：直接进内置「旅游行程」模块（与每日看板互不干扰）。
- 一日游×4：都江堰—青城山、熊猫基地—宽窄巷子—锦里、西岭雪山滑雪、黄龙溪—天府芙蓉园
- 多日游×3：乐山—峨眉山 3 日、川西小环线（都江堰—四姑娘山—丹巴—新都桥—康定）4 日、青城山—街子—平乐 2 日
每条行程都含真实时间段、地点、交通/美食/景点标签和贴士。

## 数据里的两个巧思（为什么值得体验）

1. **每日随机性**：核心学习块按约 72% 完成 / 部分完成 / 跳过 混合，生活块几乎必做。翻看任意一天都不会是"完美打卡"，更接近真实自律状态。
2. **跨天连续性（头天没完成→第二天体现）**：某天跳过的计划，会在第二天同一时段的待办里出现「补做：XXX」；校验脚本已确认这些补做待办确实来自前一天的 skip 状态——真实还原"今天没做完，明天接着补"的自律故事线。

每个科目都填了可信的**目标 + 方法提示（extra）+ 分层里程碑**（部分已完成、部分待启动），所以「学习进度」「周对比」「项目周报」无须自己录数据就有内容。

## 这个应用还能用在这些场景

- **备孕 / 孕期健康管理**：作息、营养、产检提醒、适度运动的时间轴
- **减肥健身打卡**：饮食记录、训练计划、体测曲线，固定待办强化动作
- **自由职业 / 远程办公作息**：把"没有固定上下班"排成自律时间轴，避免昼夜颠倒
- **其它执业资格考试**：教资、注会、法考、医师、建造师……套同一套「阶段 + 里程碑」模板
- **亲子陪伴计划**：每日亲子阅读 / 运动 / 沟通时间块，家庭节奏可视化
- **副业变现推进**：副业项目里程碑 + 每周投入时长，防止主业挤掉成长
- **戒瘾 / 习惯养成**：用固定待办 + 连续打卡天数，把"坚持"变成看得见的曲线
- **读研科研进度**：组会、实验、论文、文献按甘特式推进，避免论文季暴毙
- **备考语言 / 出国**：单词、听力、申请节点倒计时一站式管理
- **家庭事务 / 装修进度**：把大工程拆成每日小块，今天推进一点

任意场景都能用「编辑计划」套模板，或用「智能导入」拍照识别课表 / 排班表，一分钟变看板。
