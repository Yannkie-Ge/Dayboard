⚙ AI 模型设置

Ollama · 本地推理
OpenAI 兼容模式适用于通义 DashScope、Kimi、DeepSeek、智谱、本地 LM Studio / vLLM 等提供 /v1/chat/completions 的服务。地址填到 /v1 即可（没带会自动补）。
电脑本机用 http://localhost:11434；手机端请填电脑局域网 IP（如 http://192.168.1.7:11434），且电脑 Ollama 须以 OLLAMA_HOST=0.0.0.0:11434 启动。
「拍照识日程」（课表 / 旅游行程 / 通用日程）等看图功能须用多模态模型（纯文本模型如 qwen3.6:35b 看不了图）。在此填入你本地已 pull 的视觉模型名（如 qwen2.5vl:32b）。
「上下文窗口」是发给模型时的 num_ctx。若经代理 / 不同模型调用 Ollama，上游常以小窗口（如 2048/4096）加载模型，而本 App 的「最大输出」默认 4096，两者相加便超过上游窗口 → 报 400 input length too long。显式声明此窗口即可根治。默认 262144（与本地 OLLAMA_CONTEXT_LENGTH 一致）。
qwen3 等思考模型默认会先输出 <think> 推理块，会吃掉「最大输出」预算、导致最终答案被截断为空（表现为「模型返回不是合法 JSON 数组」）。默认关闭即可稳定拿到干净结果；仅当你确实需要模型深思熟虑时（且输出较短）才勾选。
提示：先在终端跑 ollama serve，确认 http://localhost:11434/api/tags 可访问。 模型未下载先 ollama pull qwen3.6:35b。
