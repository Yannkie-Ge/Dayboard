# 科目管理 · 使用帮助

> 科目（项目）是「学习进度」的载体：每门课/每个备考科目都有独立的进度、章节、里程碑，并被今日看板的区块引用。管理好科目，进度汇总才准。

## 一、入口
- **📚 学习进度** 模块里的「管理科目 / 编辑科目」；
- 编辑计划时给学习类区块「绑定科目」也会引到科目库。

## 二、科目里有什么
每个科目（项目）可包含：
- **名称 + 颜色**：在进度、看板、总结里统一标识。
- **目标（goal）**：这个项目要达成的目标，会拼进 AI 规划 / 总结的提示词，让 AI 更懂你。
- **附加任务提示（extra）**：你给该项目的特殊要求，同样喂给 AI。
- **章节进度**：按章节记录学到哪、完成度。
- **里程碑**：拆成「阶段 + 分层里程碑」（已完成 / 进行中 / 待启动）。

## 三、怎么用
1. **新建科目**：填名称、选颜色，写清目标与附加提示。
2. **绑定区块**：在「编辑计划」里把学习类区块关联到科目，之后该块的打卡会汇总进这个科目的投入。
3. **更新进度**：在「学习进度」里维护章节 / 里程碑状态。
4. **AI 联动**：配好模型后，今日看板上该科目的区块会出现 ✍「AI 写」按钮，按今日完成情况和你写的 goal/extra 生成学习总结。

## 四、要点
- 科目是「学习进度」「周期总结·各项目投入」「AI 周报」的数据基础——名字和颜色保持一致，复盘才清楚。
- 通用备考（考研/考公/资格考）可用内置「阶段 + 里程碑」模板快速建科目。
- 删除科目不会删掉历史打卡，但相关汇总会少一项。

## 五、常见问题
**Q：科目和「项目包库」里的包是什么关系？**
A：项目包库是现成的科目/里程碑模板合集（如各职业资格考三阶段包），「导入」即生成对应科目；科目管理是对生成后的科目做日常维护。

**Q：AI 总结总写不到点？**
A：把 goal / extra 写具体（如「重点突破高数多元微分，周末模考」），AI 才有据可依。
