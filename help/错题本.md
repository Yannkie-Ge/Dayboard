# 错题本 · 使用帮助

> 备考（考研政治、考公、资格考等）的错题收集站：把做错的题结构化存下，按科目/考点归档，配合拍照识别题干，省去手抄。

## 一、入口
- 相关模块里的「错题」入口（如学习进度/项目下的错题本）；
- 「智能导入」识别到「题目 / 题干」时，文字会直接进错题本的题干框。

## 二、一条错题有什么
- **题目 / 题干**：可粘贴，或用「智能导入」拍照识别填入（见「智能导入」帮助）。
- **科目 / 考点**：归类用，便于按考点复习。
- **我的答案 / 正确答案**：对照记录。
- **错因 / 笔记**：为什么错、怎么记。
- **状态**：已掌握 / 待巩固等。

## 三、怎么用
1. **录题**：手动粘贴题干，或拍照识别自动填入题干框，再补答案与错因。
2. **归类**：选科目与考点，方便日后筛选。
3. **复习**：按科目/考点过滤，重做或回忆；标记「已掌握」移出待巩固。
4. **与进度联动**：错题可关联对应项目，复盘时一起看薄弱点。

## 四、要点
- 错题本是**备考向**的辅助模块，和「学习进度·里程碑」互补：里程碑管「学到哪」，错题本管「哪里易错」。
- 题干识别依赖「智能导入」的 OCR（端侧），AI 解析可提升准确率但需配模型。

## 五、常见问题
**Q：拍照识别的题没进错题本？**
A：识别类型要选「题目/题干」；若选成「大纲/日程」会进别的模块。确认类型再识别。

**Q：错题能导出吗？**
A：随整个看板「导出备份」一起带走（错题存在本地状态里）。

**Q：错因怎么记最有用？**
A：写「知识点盲区 / 审题失误 / 计算错」这类可行动原因，而不是只抄正确答案。
