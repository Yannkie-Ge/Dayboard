# 数据备份与恢复 · 使用帮助

> 看板数据存在浏览器本地。用「导出备份 / 导入备份」把整个状态打包成 JSON，换设备、防丢失、体验示例都靠它。

## 一、入口
底部视图栏 **数据**（或「⚙ 设置」相关面板）→ **导出备份** / **导入备份**。

## 二、导出备份
- 点「导出备份」→ 下载一份 `dailyboard-...json`，包含**整个看板状态**：打卡 `days`、周期排程 `schedules`、项目/科目、行程 `trips`、倒计时、设置等。
- 建议**定期导出**，当作存档；换电脑/清浏览器前务必导一份。

## 三、导入备份（整份替换！）
- 点「导入备份」→ 选一份 JSON → **当前看板被文件整体替换**（打卡、排程、行程、设置全换成文件里的）。
- 仓库里的 5 份演示（`demos/*.json`）就是这种整份备份，逐个导入即可体验不同场景。

> ⚠️ 导入是**整份替换**，不是合并。导入前最好先导出当前状态留底；五个示例互相独立，逐个体验即可。

## 四、和「导入行程」的区别（重要）
- **导入备份**（数据面板）= 替换整个看板。
- **📥 导入行程**（旅行日程内，见「旅行日程导入帮助」）= **只追加**行程，不动其他数据。
- 只想加几趟旅行 → 用旅行模块的导入行程；想整体切换场景 → 用导入备份。

## 五、常见问题
**Q：导入后想要回原来的？**
A：如果导入前导出了备份，再「导入备份」选那份即可恢复；没导出则无法回退。

**Q：换浏览器/设备数据没了？**
A：本地存储不跨设备；用导出备份带走，到新设备导入备份恢复。

**Q：导入提示失败？**
A：文件不是合法备份 JSON，或结构损坏；换一份确认正常的文件。
