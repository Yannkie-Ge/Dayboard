# 设置 · 使用帮助

> 看板的基础偏好 + AI 模型开关都在这。改完即时生效，随备份带走。

## 一、入口
底部视图栏 **⚙ 设置**（或顶部齿轮）。

## 二、基础设置
- **主题 / 显示偏好**：明暗、密度等（按版本提供）。
- **默认专注时长等习惯项**：如番茄钟「运行到本时段结束」的记忆。
- **数据相关**：导出/导入备份入口也常挂在这里或「数据」面板。

## 三、AI 模型设置（关键）
要让 AI 能力（规划/周报/撰写/写总结/拍照识别的 AI 解析）可用，需填：
- **服务地址**：你的模型 API 基址（如兼容 OpenAI 的 `/v1` 地址）。
- **模型名**：对话模型（如 `qwen` 系列等）。
- **视觉模型**（识别用）：做图片 OCR/结构化时用的多模态模型。
- **密钥**：对应服务的 API Key。

填好后 AI 按钮才生效；没填则提示「先去设置填好模型」。

## 四、要点（隐私）
- **不填模型 = 纯离线**：打卡、统计、冥想、导入行程全部本地跑，不出本机。
- 填了模型后，相关文本只发往你写的地址——你掌控数据去向。
- 设置本身存在本地，随「导出备份」带走；换设备记得也导一份。

## 五、常见问题
**Q：AI 一直转圈/报错？**
A：地址或模型名不对、密钥失效、或网络不通。先确认别家客户端能用同配置，再回来测。

**Q：不想用 AI 了？**
A：清空模型设置即可，看板退回完全离线模式，不影响任何已有数据。

**Q：设置会丢吗？**
A：存在本地；清浏览器缓存或换设备会丢，记得用「导出备份」一并保存。
