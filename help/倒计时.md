# 倒计时 · 使用帮助

> 把「考研 / 考试 / 出发行程」等关键节点放在一眼能看到的地方，倒计时提醒你离目标还有多久。

## 一、入口
底部视图栏 **⏳ 倒计时**。

## 二、它有什么
- 一组**倒计时卡片**：每个卡片 = 一个关键日期（如「考研初试 2026-12-21」「成都出发 2026-10-02」）。
- 实时显示「距今 N 天」，临近时更醒目。

## 三、怎么用
1. **新建倒计时**：填名称 + 目标日期（可附备注/分类）。
2. **编辑 / 删除**：随时调整或移除。
3. 常来本视图看还差多少天，配合「旅行日程」的出发日、各考试的报名/考试日做整体时间感管理。

## 四、要点
- 倒计时和「旅行日程」的出行日期、各项目的里程碑日期是**互补**的：里程碑管「进度到哪」，倒计时管「离deadline 还有多久」。
- 数据存本地，随备份带走。

## 五、常见问题
**Q：能不能和考试/旅行自动联动？**
A：目前是独立维护的；你可以把旅行出发日、考试日手动建一条倒计时，和对应模块对齐即可。

**Q：过了目标日期还会显示吗？**
A：通常显示「已过期 / 0 天」，可删掉或留作纪念。

**Q：倒计时能提醒我吗？**
A：看板本身不弹系统通知；它提供常驻的「还剩几天」视觉提醒，配合你自己的日程习惯使用。
