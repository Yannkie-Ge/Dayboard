# Dayboard · 全天候成长看板

> 一个**单文件、完全离线**的个人时间管理利器：把「时段排程 → 打卡 → 复盘 → 数据分析 → AI 辅助」串成一整块看板的闭环。
> 双击即用，数据存本地，无需账号、无需联网、无外部依赖。

---

## 🎯 六大场景，开箱即懂

Dayboard 是以下每一类的**时间管理利器**，每类都配了可直接导入的示例数据：

| 场景 | 怎么用 |
|---|---|
| 🎓 **考研助手** | 数学/英语/政治/专业课四科强化排布 + 周日模考 + 逐章里程碑，倒计时挂初试/报名 |
| 🏛 **考公助手** | 在职节奏「通勤碎片 + 晚间整块 + 周末模考」，行测/申论/时政/公文四科推进 |
| 📜 **职业资格考试助手** | 教资、注会、法考、医师、建造师、药师……同一套「阶段 + 里程碑」模板，考期倒计时 |
| 🤰 **孕期管理** | 孕中期 21 天真实作息：轻工作 + 孕动 + 胎动观察 + 产检清单 + 待产包，5 条目标线带里程碑 |
| ✈️ **旅游助手** | 独立的「旅行日程」模块：一日游/多日游按天排布，支持拍照 AI 识别 + 一键导入现成行程 |
| 💼 **上班族时间管理** | 把通勤、会议、健身、学习挤进朝九晚六之外的时间轴，四象限 todo 防遗漏 |

不是又一个待办清单，而是一块**全天候**的「成长驾驶舱」——从清晨起床到深夜复盘，学习、备考、工作、健身、旅行、孕期都能在同一块看板里被安排、被记录、被看见。

## 🚀 快速开始

**方式一：双击打开（最简单）**
直接双击 `index.html`，用任意现代浏览器打开即可。无需安装、无需服务器。

**方式二：部署到静态托管（可分享 / 手机访问）**
把本仓库整个目录丢到任意静态托管（GitHub Pages、Vercel、Netlify、对象存储…）即可。
例如开启 GitHub Pages 后，访问 `https://<你的用户名>.github.io/<仓库名>/` 就能在线使用。

**方式三：鸿蒙 NEXT 原生 App**
项目已支持通过 `rawfile` 资产封装为 HarmonyOS NEXT 原生应用，离线可装、桌面即点。

## 📥 一键体验：导入 6 份示例数据

仓库里准备了 **6 份完整演示备份**，让你「拿来就能体会价值」——每份都是一份全量备份 JSON，导入即把整个看板替换成对应场景的真实排布（含 21 天打卡、跨天连续性、项目里程碑）。

| 文件 | 场景 | 看点 |
|---|---|---|
| `demos/junior-demo.json` | 初中课程学习及假期安排 | 上学日 / 周末弹性双作息，7 科带章节进度 |
| `demos/uni-demo.json` | 大学课程学习 | 上课·图书馆·健身·社团·科研·论文多线程 |
| `demos/civil-demo.json` | 上班族考公日程 | 通勤碎片 + 晚间整块 + 周末模考的在职节奏 |
| `demos/kaoyan-focus-demo.json` | 专心考研备考（强化阶段） | 全天深耕作息，周日模考，4 科强化进度 |
| `demos/travel-chengdu-demo.json` | 成都周边旅游行程 | 4 条一日游 + 3 条多日游，进「旅行日程」模块 |
| `demos/pregnancy-demo.json` | **孕期管理 · 孕中期节奏** | 轻工作 + 孕动 + 胎动观察 + 产检清单 + 待产包，5 周目标带里程碑 |

**导入步骤**
1. 打开看板（双击 `index.html`）。
2. 进入底部「**数据**」面板 → 点「**导入备份**」。
3. 选择上面任意一个 JSON 文件即可。

> ⚠️ 导入是**整份替换**当前状态，六个示例互相独立，逐个导入体验即可。
> 导入后数据落在历史日期（例如孕期示例为 `2026-08-31 ~ 2026-09-20`），想看填充的打卡，请在「今日看板」点顶部**日期文字**（或底部 🗓️ 日历）翻到对应日期。
> 更详细的演示说明见 [`demos/成长看板示例包-说明.md`](demos/成长看板示例包-说明.md)。

> 💡 只想把成都周边示例的 7 条行程加进**当前**看板、而不替换整个看板？进入「✈️ 旅行日程」→「📥 导入行程」选同一文件即可（见下方「旅行日程：新建与导入」）。

## 🧭 界面导览

顶部视图切换 + 底部快捷入口，覆盖一天到一年的完整闭环：

- **📋 今日看板** —— 按「生活 / 学习 / 健康 / 心智 / 休息 / 业务 / 机动」分时段排布；每块可标记 ✓ 完成 / ◐ 部分 / ✕ 跳过；含「今日成就（写下 3 件有掌控感的事）」「今日总结 & 状态（心情 / 精力 / 睡眠）」「当日感悟」。
- **🎯 待办看板** —— 按「重要 / 紧急」四象限分级；自带「收集箱 + AI 自动整理」，碎片想法先收后理；含时间冲突检测。
- **📚 学习进度** —— 项目 / 科目维度，带分层里程碑（已完成 / 进行中 / 待启动），进度一目了然。
- **📊 数据分析** —— 30 天核心完成率、时间投入分布、专注时长趋势、打卡热力图、状态（精力 / 心情）与产出对比、徽章墙。
- **📑 周期总结** —— 自动汇总结束的周 / 阶段，形成可回看的成长档案。
- **📈 周 / 双周对比** —— 相邻周期横向对比，看清节奏变化。
- **🔍 检索回顾** —— 按日期回看「那天做了什么、完成得怎样、收获了什么」；关键词全文检索（时段 / 待办 / 备注 / 收获 / 复盘）；按项目生成总结 + 规则建议，可让 AI 基于真实记录深度点评（详见下方「检索回顾」）。
- **📕 拆书工作台** —— 把一本书当一个项目：书前报告（AI 生成 / 手动模板双通道，逐块可重写）→ 以「概念」为验收单位的里程碑骨架 → 创建入「阅读队列」后点火拆读（详见下方「拆书工作台」）。
- **🧘 冥想舱** —— 实时合成的环境音场（无需联网）、4-2-6 呼吸节律引导、近 14 天冥想时长与打卡明细。
- **✈️ 旅行日程** —— 与每日看板完全分离的行程模块；支持拍照 / 选图由 AI 识别攻略生成行程，也支持「📥 导入行程」批量载入现成 `.json`（详见下方「旅行日程：新建与导入」）。
- **⏳ 倒计时** —— 考研 / 考公 / 产检 / 考试 / 出发行程等关键节点的倒数。
- **🗓️ 日历** —— 月历总览，点任意日期跳转到那天看板。

## 🔍 检索回顾：查得到、算得清、给得出建议

「🔍 检索回顾」视图回答三个问题：**那天我做了什么？某个项目整体怎么样？接下来该怎么调？**

1. **📅 按日期查** —— 选一个日期，一页看全当天：各时段完成状态（✓ 完成 / ◐ 部分 / ✗ 跳过）、待办（已完成 / 未完成）、时段备注、各项目的当日收获、当日成就 / 感悟 / 复盘。
2. **🔎 关键词检索** —— 一个词搜遍所有历史：时段标题、待办、备注、项目收获、当日复盘都是检索范围；每条命中可一键「去那看」跳回当天详情。
3. **📂 项目总结 + 建议** —— 选定项目，自动聚合：记录天数、累计专注、时段完成率、里程碑进度、收获沉淀清单；并给出规则建议（断更提醒、完成率偏低降档建议、推进当前里程碑、投入量对照周目标等）。
4. **✨ AI 增强（可选）** —— 配好本地 Ollama 后，可对「某一天」或「某个项目」生成基于真实记录的深度总结与 3 条可执行建议；不配置也能用，规则版建议零依赖。

## 📕 拆书工作台：一本书 = 一个项目

「📕 拆书工作台」把"拆一本书"变成一条可验收的项目流水线：**书前报告 → 里程碑骨架 → 阅读队列**，先想清楚再动笔，读完有交代。

1. **① 书目资料** —— 填书名 / 作者 / 页数 / 类型（教材工具 · 科普认知 · 商业方法论 · 小说文学 · 哲学经典 · 应试职业）、报告档位（深度 ~4000 字 / 轻量 ~1500 字）、拆书周期（14 / 21 / 30 天），并把目录粘贴进来（一行一章）。
2. **② 书前报告（开读前的关卡）** —— 「✨ AI 生成书前报告」走本地 Ollama，输出 8 个区块：一句话定位 · 全书概述 · 它能帮你什么/读它的意义 · 类型判断与读法总纲 · 从哪里开始读 · 各章简述 · 重点章节 ⭐ · 读完后读什么；每个区块都可单独「↻ 重写这块」，也支持「📝 手动模板」无 AI 兜底。报告全文随项目双写存档。
3. **③ 里程碑骨架（概念轴）** —— 里程碑以**需要掌握的概念**为验收单位（而非单纯章节）：从目录一键导入后，逐条标深度（⭐ 核心必须 A 级掌握 / 过章 / 参考可跳）、写「怎样算会」的验收标准、附验收问句；章节只是排程轴。
4. **📚 阅读队列（点火机制）** —— 创建的书默认「⏸ 待执行」排进队列，点「🔥 点火」才转为「执行中」开始排程拆书；拆完一本，报告里推荐的下一本就在这里点火接续。

> 后续迭代：类型化排程模板（不同书型不同拆法）→ P/A/C/I 四层每日循环（I 层六式拷问定级）→ 25/50/75% 检查点抽问与拆书卡。

## 🔧 核心概念

- **时段区块（Block）**：一天被切成多个时段块，每块归属一个分类（生活 / 学习 / 健康 / 心智 / 休息 / 业务 / 机动），可排具体时间与备注。
- **打卡状态**：每块记 `done / part / skip`，统计与热力图据此计算。
- **项目 / 科目里程碑**：把大目标拆成「阶段 + 分层里程碑」，学习进度与周报自动汇总，不用每天手填。
- **区间周期排程**：支持「学期 / 假期 + 每周重复」的方案，按日期自动套用对应星期几的排布；可同时存在多套方案（如上学日方案 + 寒暑假方案）。
- **待办四象限**：重要且紧急的先做，重要的排进计划，紧急不重要的授权 / 快速处理，不重要的删掉。
- **旅行独立模块**：行程数据单独存放，与每日打卡、周期排程互不干扰。

## ✈️ 旅行日程：新建与导入

「旅行日程」是与每日看板、周期排程完全独立的行程模块。添加行程有两种方式，互不冲突：

- **＋ 新建行程**：手动逐步填写标题、日期与当天事项（时间 / 地点 / 备注 / 类型）。
- **📥 导入行程**：直接载入现成的 `.json` 行程文件，批量进入，无需一条条手填。

**导入行程支持的格式**（自动识别）
1. 整份备份 JSON（含 `trips` 数组）——例如 `demos/travel-chengdu-demo.json`，会自动取其中的行程部分；
2. 纯行程数组 `[ { ... }, { ... } ]`；
3. 单条行程对象 `{ "id": ..., "title": ..., "days": [ ... ] }`。

**与「导入备份」的关键区别**
- 「数据」面板的**导入备份**＝整份替换当前看板（含打卡、排程、行程），六个示例互相独立；
- 「旅行日程」内的**导入行程**＝**只追加行程**，不触碰你已有的打卡 / 排程 / 其他数据；若导入的行程 id 已存在会自动改名避免冲突。

> 想快速体验：进入「旅行日程」→ 点「📥 导入行程」→ 选 `demos/travel-chengdu-demo.json`，即可把 7 条成都周边行程（4 条一日游 + 3 条多日游）加进当前看板，与你的日常打卡并行存在。

> 更详细的字段说明、三种文件格式示例与常见问题，见 [`旅行日程导入帮助.md`](旅行日程导入帮助.md)。

## 🤰 孕期管理：一条完整的时间轴

孕期不是「少做事」，而是「把对的事排进每一天」。`pregnancy-demo.json` 给出一条可参考的孕中期作息（24~26 周）：

- **工作日**：起床温水 → 早餐 + 补剂 → 轻工作（每小时起身 5 分钟）→ 小睡 → 傍晚散步 → 孕动瑜伽 → **胎动观察** → 泡脚 → 早睡
- **周六**：胎教 + 公园长走 + 孕记周小结
- **周日**：胎动记录 + 待产包整理 + 孕育知识阅读
- **5 条目标线**：营养与体重 / 孕运动 / 胎动观察 / 产检清单 / 待产包，每条带「阶段 + 分层里程碑」
- **3 个倒计时**：26 周小产检 / 28 周转周检 / 预产期（40 周）

> ⚠️ 本示例仅为**时间管理参考**，不构成医疗建议。产检时间、运动强度、补剂用法请以产科医生意见为准。

## 🤖 AI 增强（可选）

看板内置多项 AI 能力：AI 项目周报、AI 辅助撰写、AI 规划排程、拍照识别行程等。
这些功能**默认关闭**，需要在「⚙ 设置 → AI 模型设置」里自行配置模型（API 地址 / 密钥 / 模型名）后才会启用——你的数据只在这一步之后才可能与你配置的模型交互，基础打卡与统计完全本地运行。

## 💾 数据与隐私

- **完全离线**：单文件 HTML，无任何外部脚本 / 网络依赖，断网也能用。
- **本地存储**：所有数据存在浏览器 `localStorage`，**不出本机**。
- **备份自由**：随时「导出备份」生成 JSON，换设备 / 防丢失只需再「导入备份」。
- **可控的 AI**：仅当你主动配置模型后，相关文本才会发送到你指定的接口。
