# 全天候成长看板 · Daily Board

> 一个**单文件、完全离线**的个人成长与时间管理看板：把「时段排程 → 打卡 → 复盘 → 数据分析 → AI 辅助」串成闭环。
> 双击即用，数据存本地，无需账号、无需联网、无外部依赖。

---

## ✨ 一句话定位

不是又一个待办清单，而是一块**全天候**的「成长驾驶舱」——从清晨起床到深夜复盘，学习、备考、工作、健身、旅行都能在同一块看板里被安排、被记录、被看见。

## 🚀 快速开始

**方式一：双击打开（最简单）**
直接双击 `index.html`，用任意现代浏览器打开即可。无需安装、无需服务器。

**方式二：部署到静态托管（可分享 / 手机访问）**
把本仓库整个目录丢到任意静态托管（GitHub Pages、Vercel、Netlify、对象存储…）即可。
例如开启 GitHub Pages 后，访问 `https://<你的用户名>.github.io/<仓库名>/` 就能在线使用。

**方式三：鸿蒙 NEXT 原生 App**
项目已支持通过 `rawfile` 资产封装为 HarmonyOS NEXT 原生应用，离线可装、桌面即点。

## 📥 一键体验：导入示例数据

仓库里准备了 **5 份完整演示备份**，让你「拿来就能体会价值」——每份都是一份全量备份 JSON，导入即把整个看板替换成对应场景的真实排布（含 21 天打卡、跨天连续性、项目里程碑）。

| 文件 | 场景 | 看点 |
|---|---|---|
| `demos/junior-demo.json` | 初中课程学习及假期安排 | 上学日 / 周末弹性双作息，7 科带章节进度 |
| `demos/uni-demo.json` | 大学课程学习 | 上课·图书馆·健身·社团·科研·论文多线程 |
| `demos/civil-demo.json` | 上班族考公日程 | 通勤碎片 + 晚间整块 + 周末模考的在职节奏 |
| `demos/kaoyan-focus-demo.json` | 专心考研备考（强化阶段） | 全天深耕作息，周日模考，4 科强化进度 |
| `demos/travel-chengdu-demo.json` | 成都周边旅游行程 | 4 条一日游 + 3 条多日游，进「旅行日程」模块 |

**导入步骤**
1. 打开看板（双击 `index.html`）。
2. 进入底部「**数据**」面板 → 点「**导入备份**」。
3. 选择上面任意一个 JSON 文件即可。

> ⚠️ 导入是**整份替换**当前状态，五个示例互相独立，逐个导入体验即可。
> 导入后数据落在历史日期（例如考研示例为 `2026-07-05 ~ 2026-07-25`），想看填充的打卡，请在「今日看板」点顶部**日期文字**（或底部 🗓️ 日历）翻到对应日期。
> 更详细的演示说明见 [`demos/成长看板示例包-说明.md`](demos/成长看板示例包-说明.md)。

> 💡 只想把成都周边示例的 7 条行程加进**当前**看板、而不替换整个看板？进入「✈️ 旅行日程」→「📥 导入行程」选同一文件即可（见上方「旅行日程：新建与导入」）。

## 🧭 界面导览

顶部视图切换 + 底部快捷入口，覆盖一天到一年的完整闭环：

- **📋 今日看板** —— 按「生活 / 学习 / 健康 / 心智 / 休息 / 工作」分时段排布；每块可标记 ✓ 完成 / ◐ 部分 / ✕ 跳过；含「今日成就（写下 3 件有掌控感的事）」「今日总结 & 状态（心情 / 精力 / 睡眠）」「当日感悟」。
- **🎯 待办看板** —— 按「重要 / 紧急」四象限分级；自带「收集箱 + AI 自动整理」，碎片想法先收后理；含时间冲突检测。
- **📚 学习进度** —— 项目 / 科目维度，带分层里程碑（已完成 / 进行中 / 待启动），进度一目了然。
- **📊 数据分析** —— 30 天核心完成率、时间投入分布、专注时长趋势、打卡热力图、状态（精力 / 心情）与产出对比、徽章墙。
- **📑 周期总结** —— 自动汇总结束的周 / 阶段，形成可回看的成长档案。
- **📈 周 / 双周对比** —— 相邻周期横向对比，看清节奏变化。
- **🧘 冥想舱** —— 实时合成的环境音场（无需联网）、4-2-6 呼吸节律引导、近 14 天冥想时长与打卡明细。
- **✈️ 旅行日程** —— 与每日看板完全分离的行程模块；支持拍照 / 选图由 AI 识别攻略生成行程，也支持「📥 导入行程」批量载入现成 `.json`（详见下方「旅行日程：新建与导入」）。
- **⏳ 倒计时** —— 考研 / 考试 / 出发行程等关键节点的倒数。
- **🗓️ 日历** —— 月历总览，点任意日期跳转到那天看板。

## 🔧 核心概念

- **时段区块（Block）**：一天被切成多个时段块，每块归属一个分类（生活 / 学习 / 健康 / 心智 / 休息 / 工作），可排具体时间与备注。
- **打卡状态**：每块记 `done / part / skip`，统计与热力图据此计算。
- **项目 / 科目里程碑**：把大目标拆成「阶段 + 分层里程碑」，学习进度与周报自动汇总，不用每天手填。
- **区间周期排程**：支持「学期 / 假期 + 每周重复」的方案，按日期自动套用对应星期几的排布；可同时存在多套方案（如上学日方案 + 寒暑假方案）。
- **待办四象限**：重要且紧急的先做，重要的排进计划，紧急不重要的授权 / 快速处理，不重要的删掉。
- **旅行独立模块**：行程数据单独存放，与每日打卡、周期排程互不干扰。

## ✈️ 旅行日程：新建与导入

「旅行日程」是与每日看板、周期排程完全独立的行程模块。添加行程有两种方式，互不冲突：

- **＋ 新建行程**：手动逐步填写标题、日期与当天事项（时间 / 地点 / 备注 / 类型）。
- **📥 导入行程**：直接载入现成的 `.json` 行程文件，批量进入，无需一条条手填。

**导入行程支持的格式**（自动识别）
1. 整份备份 JSON（含 `trips` 数组）——例如 `demos/travel-chengdu-demo.json`，会自动取其中的行程部分；
2. 纯行程数组 `[ { ... }, { ... } ]`；
3. 单条行程对象 `{ "id": ..., "title": ..., "days": [ ... ] }`。

**与「导入备份」的关键区别**
- 「数据」面板的**导入备份**＝整份替换当前看板（含打卡、排程、行程），五个示例互相独立；
- 「旅行日程」内的**导入行程**＝**只追加行程**，不触碰你已有的打卡 / 排程 / 其他数据；若导入的行程 id 已存在会自动改名避免冲突。

> 想快速体验：进入「旅行日程」→ 点「📥 导入行程」→ 选 `demos/travel-chengdu-demo.json`，即可把 7 条成都周边行程（4 条一日游 + 3 条多日游）加进当前看板，与你的日常打卡并行存在。

> 更详细的字段说明、三种文件格式示例与常见问题，见 [`旅行日程导入帮助.md`](旅行日程导入帮助.md)。

## 🤖 AI 增强（可选）

看板内置多项 AI 能力：AI 项目周报、AI 辅助撰写、AI 规划排程、拍照识别行程等。
这些功能**默认关闭**，需要在「⚙ 设置 → AI 模型设置」里自行配置模型（API 地址 / 密钥 / 模型名）后才会启用——你的数据只在这一步之后才可能与你配置的模型交互，基础打卡与统计完全本地运行。

## 💾 数据与隐私

- **完全离线**：单文件 HTML，无任何外部脚本 / 网络依赖，断网也能用。
- **本地存储**：所有数据存在浏览器 `localStorage`，**不出本机**。
- **备份自由**：随时「导出备份」生成 JSON，换设备 / 防丢失只需再「导入备份」。
- **可控的 AI**：仅当你主动配置模型后，相关文本才会发送到你指定的接口。
