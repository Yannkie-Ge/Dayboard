新手引导 · 使用帮助

第一次打开看板时的「快速上手」流程，帮你几分钟内把日程排起来、把打卡跑通，不用先读完整本手册。

一、什么时候出现

首次打开（或重置后）自动弹出引导；也可在设置里重新打开。

二、引导会带你做什么

  1. 选场景 / 套模板：从 中小学、大学、考公、考研 等预设里选一个，一键生成一周的时段排布。
  2. 认识三块主区：今日看板（打卡）、待办看板（任务）、学习进度（项目/里程碑）。
  3. 走一遍打卡：教你在区块上标 ✓/◐/✕，并写一条当日成就。
  4. 了解进阶：提示「编辑计划」改排程、「数据 → 导入备份」体验示例、「设置」开关 AI。

三、快速上手五步（浓缩版）

  1. 双击 index.html 打开。
  2. 引导里选一个预设模板（或直接去「编辑计划」自建）。
  3. 到「📋 今日看板」按当天实际点打卡。
  4. 想体验成品效果：去「数据 → 导入备份」，选 demos/ 里任意一个 JSON。
  5. 有需要再开 AI：去「⚙ 设置 → AI 模型设置」填模型。

四、要点

  • 引导只是「起步加速器」，随时可跳过或在设置里重看。
  • 不选模板也行——空看板也能直接打卡，之后再慢慢补排程。
  • 所有引导操作都本地生效，不会上传任何数据。

五、常见问题

Q：引导关掉了还想再看？

A：在「⚙ 设置」里找「重新打开新手引导 / 重置引导」之类的入口再次启动。

Q：选了模板但想改？

A：去「编辑计划」按自己节奏改区块即可，模板只是起点。

Q：关掉引导后一片空白？

A：说明还没有排程——去「编辑计划」加区块，或「导入备份」载入示例。

今日看板 · 使用帮助

看板的「主驾驶舱」。从清晨到深夜，一天被切成多个时段区块，你在每块上打卡、写总结，日积月累形成完整成长记录。

一、入口

底部视图栏切到 📋 今日看板（默认首页）。顶部日期文字可点击，配合底部 🗓️ 日历可翻到任意一天。

二、时段区块（Block）

一天按「生活 / 学习 / 健康 / 心智 / 休息 / 工作」六大分类切成若干区块，每块有：

  • 起止时间（如 07:00 – 08:00）
  • 标题（如「数学模考」「晨跑」）
  • 所属分类（决定统计归类与配色）

区块由「编辑计划 / 周期排程」按星期几自动套用，也可被单次调整（智能导入、旅行规划）覆盖。

三、怎么用（每日三步）

  1. 打卡：每块右侧标记状态
  • ✓ 完成（done）
  • ◐ 部分（part，算一半时长）
  • ✕ 跳过（skip）
  • 不点 = 未打卡，统计不计入
  1. 写当日复盘（每天末尾）：
  • 今日成就：写下 3 件有掌控感的事（正向反馈，强化坚持）
  • 今日总结 & 状态：记录心情 / 精力 / 睡眠
  • 当日感悟：随手记想法、灵感、卡点
  1. 块级 AI 总结（可选）：学习类区块带 ✍ 按钮，配好 AI 模型后，可让 AI 根据你今日完成情况自动写该项目的学习总结。

四、要点

  • 完成率、连续打卡天数、专注时长都基于这里的打卡状态计算，是「数据分析」「周期总结」的数据来源。
  • 翻到历史日期补打卡也有效——示例数据多落在历史日期，想看填充效果请切到对应日期。
  • 顶部 KPI（连续打卡 / 完成率 / 专注分钟）实时反映当天。

五、常见问题

Q：区块太多/太少，怎么改？

A：去「编辑计划」（周期排程）增删区块、调时间，改完后对应星期自动套用。

Q：某天临时有事，不想按排程来？

A：直接在当天拖动/编辑区块即可，只影响那一天；或用「智能导入」把课表/排班识别进来覆盖当天。

Q：AI 写总结点不动？

A：需先在「⚙ 设置 → AI 模型设置」配置模型，否则按钮提示「先填好模型」。

番茄钟 · 使用帮助

把「专注」变成看得见的一段段时间。番茄钟和今日看板的时段区块联动，帮你把计划真正坐实成专注时长。

一、入口

  • 顶部/区块工具栏的 🍅 番茄钟 按钮；
  • 或直接在某条时段区块上启动，自动锁定到这一块。

二、它怎么工作

打开番茄钟时会自动锁定「本时段计划」——即当前时刻落在 [起,止] 内的当日区块，显示成「起–止 · 标题」，并据此算出默认时长。

  • 运行到本时段结束（开关，记忆上次选择）：勾选后，计时长度 = 到该区块结束时间为止，到点自动停。适合「这一节自习就专注到下课」。
  • 不勾选则按区块时长（或默认 25 分钟）整段计时。

三、怎么用

  1. 点 🍅 打开弹窗，确认锁定的区块/时长。
  2. 点 开始 → 圆环进度走动，状态显示「专注中 · 约 HH:MM 结束」。
  3. 中途可 暂停（再点继续）；结束前可随时停。
  4. 时间到会 响一声提醒「这一轮结束了」，按钮变「再来一轮」。
  5. 点「再来一轮」按同样设置重新开始。

四、要点

  • 专注时长会累计进当天的「专注分钟」，并计入「数据分析」的专注趋势与徽章。
  • 锁定的区块时长来自你的排程；没排程时退化为默认专注时长。
  • 「运行到本时段结束」只在今天且该区块尚未结束时可勾选。

五、常见问题

Q：番茄钟和区块打卡是一回事吗？

A：不是。打卡记「这块做没做」，番茄钟记「实际专注了多久」。两者都会进统计，但维度不同。

Q：没有声音提醒？

A：浏览器通常要求先有交互才允许播放声音；首次点「开始」即已解锁音频，后续结束提醒可正常响。

Q：想自定义 25/5 节奏？

A：目前时长取自区块或默认专注值；「运行到本时段结束」是推荐的贴合排程用法。

待办看板 · 使用帮助

用「重要 / 紧急」四象限管理任务，配「收集箱 + AI 自动整理」把碎片想法先收后理，还有时间冲突检测帮你排得下。

一、入口

底部视图栏 🎯 待办看板。

二、四象限

任务按两个维度落位：

  • 重要且紧急：立刻做。
  • 重要不紧急：排进计划（看板区块 / 项目里程碑）。
  • 紧急不重要：授权或快速处理。
  • 不重要不紧急：删掉或以后再说。

三、怎么用

  1. 收集箱速记：脑中冒出的事先丢进「收集箱」，不打断当下；空闲时再整理。
  2. AI 自动整理（需配模型）：把收集箱里的一堆想法交给 AI，自动归类、拆解、排进四象限。
  3. 建任务：填标题、选象限、可设日期/关联项目、备注。
  4. 时间冲突检测：给任务排了具体时段后，系统检测与看板区块/其他任务的重叠，提示你顺延或调整。
  5. 完成/归档：做完标记完成，沉淀进历史。

四、要点

  • 待办和「今日看板区块」是两套：待办是任务清单，区块是时间排布。把重要不紧急的待办落成区块，才算排进日程。
  • AI 整理依赖「设置 → AI 模型设置」；未配置时收集箱仍可手动整理。
  • 冲突检测关注的是「同一时段被排满」，帮你避免计划看起来很满、实际做不完。

五、常见问题

Q：AI 整理不动？

A：先去「⚙ 设置 → AI 模型设置」填好服务地址/模型/密钥。

Q：四象限和日程区块重复了吗？

A：不重复。待办解决「做什么、先做什么」，区块解决「几点做」；两者通过「落成区块」打通。

Q：收集箱会丢吗？

A：收集箱内容存在本地，和看板一起随「导出备份」带走；整理前不会消失。

日历 · 使用帮助

一页看全月，点任意日期直达那天看板。补课、补打卡、回看历史都靠它。

一、入口

底部视图栏 🗓️ 日历（今日看板顶部的日期文字点开也是它）。

二、它有什么

  • 月历总览：当前月及前后月份网格，每天一个格子。
  • 完成率着色：有打卡的日期按完成率上色（越绿越高），一眼看出哪天充实、哪天空了。
  • 今日高亮：当前日期特殊标记。

三、怎么用

  1. 翻月：左右切换月份。
  2. 点某天 → 跳到那天「今日看板」，可打卡 / 写总结 / 补复盘。
  3. 从数据散点回看：在「数据分析」热力图点某天也会跳到这里对应的那天。
  4. 历史示例数据多落在具体日期（如考研示例 2026-07-05~07-25），翻到对应日期才能看到填充的打卡。

四、要点

  • 日历是「导航」，不存数据；它读的是 days 里各天的打卡状态。
  • 想看某天详情，点进去即可；想看长期趋势，去「数据分析」的 16 周热力图。

五、常见问题

Q：某天是灰的/无着色？

A：那天没有打卡记录（完成率 0），着色逻辑只对有记录的日子生效。

Q：点日期没反应？

A：通常会切到那天看板；若卡住，刷新页面或检查是否在点「今天」本身（已停在今日）。

Q：能直接在这里打卡吗？

A：不能，日历只导航；打卡在「今日看板」对应那天做。

编辑计划与周期排程 · 使用帮助

这是看板的「作息发动机」：你定义好一天由哪些时段区块组成、按星期几套用，看板就每天自动把对应排布铺好。支持「学期 / 假期」等多套方案并存。

一、入口

  • 今日看板顶部「编辑计划」或「数据 → 计划/排程」；
  • 区块上也能直接调起编辑器改某块。

二、两个概念

  • 周期排程（方案）：一套「星期几 → 当天的区块集合」的规则。例如「上学日方案」（周一~周五不同）、「寒暑假方案」。
  • 区间生效：方案可设生效区间（如 2026-09-01 ~ 2027-01-20 覆盖学期），区间内按日期自动套用对应星期几的排布。

三、怎么用

  1. 新建/选择方案：命名（如「考研强化」），设生效起止日期。
  2. 编排每周：对周一~周日分别增删区块，设定每块
  • 起止时间（s / e）
  • 标题
  • 分类（生活/学习/健康/心智/休息/工作）
  • 关联科目（学习类块可绑定科目，便于「学习进度」汇总）
  • 备注
  1. 多套并存：可同时有「上学日 + 寒暑假」两套，按日期区间自动切换，互不覆盖。
  2. 套模板：内置多种模板（中小学/大学/考公/考研…），一键生成再微调。
  3. 保存后，对应日期的看板立即按新排布渲染。

四、要点

  • 排程只定义「框架」，每天的实际打卡状态存在 days 里，互不影响。
  • 历史日期如果在方案生效区间内，翻过去也会显示对应排布（示例数据即如此）。
  • 单次调整（智能导入/旅行规划覆盖某天）不会改变常驻方案，只当天生效。

五、常见问题

Q：改了计划，为什么历史某天没变？

A：排程按日期套用；若那天在方案区间内会更新，但若你手动改过那天或那天在另一方案区间，以实际为准。

Q：想临时换一套作息（如考试周）？

A：新建一个区间覆盖考试周的方案即可，结束后自动回落到原方案。

Q：区块时间冲突会怎样？

A：编辑器允许重叠，但实际打卡统计按各自区块独立计；建议用「智能导入」的冲突策略（顺延/取消/裁剪）处理密集排班。

科目管理 · 使用帮助

科目（项目）是「学习进度」的载体：每门课/每个备考科目都有独立的进度、章节、里程碑，并被今日看板的区块引用。管理好科目，进度汇总才准。

一、入口

  • 📚 学习进度 模块里的「管理科目 / 编辑科目」；
  • 编辑计划时给学习类区块「绑定科目」也会引到科目库。

二、科目里有什么

每个科目（项目）可包含：

  • 名称 + 颜色：在进度、看板、总结里统一标识。
  • 目标（goal）：这个项目要达成的目标，会拼进 AI 规划 / 总结的提示词，让 AI 更懂你。
  • 附加任务提示（extra）：你给该项目的特殊要求，同样喂给 AI。
  • 章节进度：按章节记录学到哪、完成度。
  • 里程碑：拆成「阶段 + 分层里程碑」（已完成 / 进行中 / 待启动）。

三、怎么用

  1. 新建科目：填名称、选颜色，写清目标与附加提示。
  2. 绑定区块：在「编辑计划」里把学习类区块关联到科目，之后该块的打卡会汇总进这个科目的投入。
  3. 更新进度：在「学习进度」里维护章节 / 里程碑状态。
  4. AI 联动：配好模型后，今日看板上该科目的区块会出现 ✍「AI 写」按钮，按今日完成情况和你写的 goal/extra 生成学习总结。

四、要点

  • 科目是「学习进度」「周期总结·各项目投入」「AI 周报」的数据基础——名字和颜色保持一致，复盘才清楚。
  • 通用备考（考研/考公/资格考）可用内置「阶段 + 里程碑」模板快速建科目。
  • 删除科目不会删掉历史打卡，但相关汇总会少一项。

五、常见问题

Q：科目和「项目包库」里的包是什么关系？

A：项目包库是现成的科目/里程碑模板合集（如各职业资格考三阶段包），「导入」即生成对应科目；科目管理是对生成后的科目做日常维护。

Q：AI 总结总写不到点？

A：把 goal / extra 写具体（如「重点突破高数多元微分，周末模考」），AI 才有据可依。

学习进度与项目里程碑 · 使用帮助

把大目标拆成「阶段 + 分层里程碑」，再按日积累投入，进度一目了然。配「项目包库」可一键导入成熟备考模板。

一、入口

底部视图栏 📚 学习进度。

二、核心概念

  • 项目 / 科目：一个备考目标（如「考研数学」「教资科一」），见「科目管理」帮助。
  • 里程碑：项目下的关键节点，分层为「已完成 / 进行中 / 待启动」。
  • 投入：来自今日看板中绑定该科目的区块打卡分钟，自动汇总。
  • 风险预警：某项目近期无投入或落后，会在「周期总结」标「⚠ 高风险 / ↓ 落后」。

三、怎么用

  1. 看总览：每个项目显示颜色、累计投入分钟、里程碑 x/y、风险标签。
  2. 维护里程碑：展开项目，把完成的里程碑标记「已完成」，新阶段的标「进行中」。
  3. 导入项目包：点「项目包库」，选现成模板（职业资格考/考研各科三阶段包等）一键生成科目 + 里程碑，免手建。
  4. 周/双周对比：相邻周期横向对比见「周与双周对比」帮助，看清节奏变化。
  5. AI 周报：配好模型后，可让 AI 根据各项目近期执行情况生成周报（见「AI 增强」）。

四、要点

  • 进度不是手填的——它=里程碑状态 + 每日投入的叠加。坚持打卡，进度自然长。
  • 「项目包库」的包多为「阶段 + 分层里程碑」结构，适合长线备考；导入后可按自己节奏改。
  • 风险预警依赖「近期投入」：断更几天就会亮灯，是防止弃坑的好信号。

五、常见问题

Q：导入了项目包，但看板没变化？

A：项目包建的是「科目 + 里程碑」，要让看板出现对应区块，还需在「编辑计划」把学习块绑定这些科目（或套用包自带的排程模板）。

Q：里程碑完成率虚高？

A：里程碑是手动标记的，请按真实进度更新；投入分钟才是客观证据，两者结合看最准。

大纲编辑器 · 使用帮助

把考试大纲、课纲、复习大纲结构化成一个可勾选、可追踪进度的清单——告别「对着一页 PDF 不知道学到哪」。

一、入口

  • 项目/科目下的「大纲」入口；
  • 「智能导入」识别到「大纲」类型时，文字进大纲编辑器。

二、它能做什么

  • 结构化：把一段大纲文字（或拍照识别出的文字）整理成「章节 → 知识点」的层级清单。
  • 进度勾选：每个知识点标「未学 / 学习中 / 已掌握」。
  • 进度汇总：按章节显示完成度，和学习进度里的里程碑呼应。
  • 与 AI 联动：配好模型后可用 AI 辅助把杂乱大纲拆成层级、补说明。

三、怎么用

  1. 录入大纲：粘贴大纲文本，或拍照/选图识别（见「智能导入」）。
  2. 结构化：手动或「用 AI 解析」把文字拆成层级；确认每行的归属。
  3. 日常勾选：学完一个知识点就标记，进度自动累计。
  4. 对照里程碑：大纲完成度可映射到项目的里程碑状态，复盘时一起看。

四、要点

  • 大纲编辑器面向长线备考（考研各科、考公、资格考），让「庞大的考纲」变成可 daily 推进的清单。
  • 识别在端侧 OCR，AI 解析需配模型；结果先确认再保存。
  • 大纲数据存在本地，随备份带走。

五、常见问题

Q：识别的大纲层级乱了？

A：在编辑器里手动调整父子关系，或换「用 AI 解析」重排；确认无误再存。

Q：大纲和里程碑重复吗？

A：不重复。大纲是「考纲知识点清单」，里程碑是「项目阶段节点」；大纲完成度可支撑里程碑判断。

Q：能导出大纲吗？

A：随「导出备份」整体带走。

数据分析 · 使用帮助

把每天的打卡、专注、冥想、心情变成图表，让你「看见」自己的节奏和趋势。所有数据来自本地，断网也能看。

一、入口

底部视图栏 📊 数据分析。

二、面板包含什么

  • KPI 卡：🔥 连续打卡（天）、⏱️ 累计专注（小时）、🧘 冥想累计（分钟/天）、🏅 解锁徽章（n/总数）。
  • 核心完成率趋势：近 30 天每日完成率折线，叠加 7 日移动平均，看整体走向。
  • 专注时长趋势：近 30 天每日专注分钟柱状图；下方「周/月汇总」表给日均专注与核心完成率（近 7 天 / 近 30 天）。
  • 分类投入环形图：近 30 天按六大分类（生活/学习/健康/心智/休息/工作）的时长占比，图例带小时数。
  • 打卡热力图：16 周方格，按当日完成率上色（越绿越高），点格子可跳到那天看板。
  • 状态 vs 完成率：近 14 天「心情」与「完成率」双柱对比，检验「状态好是否做得好」。
  • 徽章墙：所有徽章及解锁日期，未解锁的显示条件暗示。

三、怎么用

  1. 日常正常打卡，数据自动积累。
  2. 定期来这里看趋势：完成率是不是在掉？专注时长够不够？哪个分类投入最少？
  3. 点热力图某天 → 跳去补看 / 复盘那天。
  4. 看徽章墙找「还差什么」的小目标。

四、要点

  • 所有指标基于 days 里的打卡状态与专注/冥想记录；不打卡的日子完成率为 0，会拉低均值——这是提醒，不是惩罚。
  • 「分类投入」只统计标记为 done/part 的区块（part 算一半时长）。
  • 趋势图随数据增长自动延伸，越用越有价值。

五、常见问题

Q：完成率忽高忽低？

A：多半是某些天没打卡（显示 0）。保持每天至少点几下，曲线才平滑可信。

Q：冥想/专注没数据？

A：先用「冥想舱」冥想、用「番茄钟」专注，记录才会进来。

Q：徽章怎么解锁？

A：按对应行为达成（如连续打卡天数、累计专注时长），达成当天自动点亮，墙上有说明。

周期总结 · 使用帮助

自动汇总结束的「周 / 阶段」，把散落在每天的努力收拢成一份可回看的成长档案。不用每天手填，到期自动生成。

一、入口

底部视图栏 📑 周期总结。

二、它能总结什么

选好区间（周 / 自定义阶段）后，自动聚合该区间：

  • KPI：记录天数（x / 总天数）、核心完成率(均)、专注时长(h)、冥想(min)、心情/精力(均)。
  • 各项目投入 · 完成情况：每个科目/项目的投入分钟 + 风险标签（✓ 正常 / ↓ 落后 / ⚠ 高风险）+ 里程碑 x/y + 累计% + 断更天数。
  • 本周期未投入 · 需关注：亮红灯/黄灯、近期零投入的项目，防弃坑。
  • 当日成就：区间内每天写的「3 件有掌控感的事」集合。
  • 复盘要点：区间内每天的总结摘要。
  • 💡 当日感悟：区间内的随手感悟。
  • 已归档总结：历史周期总结列表，可回看。

三、怎么用

  1. 周期结束（如周日晚上）来这里，选区间看总结。
  2. 重点看「风险项目」——哪些事这周期被忽略了，下周补。
  3. 把「当日成就 / 感悟」当周记回看，强化正反馈。
  4. 历史总结在「已归档」里长期留存，跨周/跨月对比用。

四、要点

  • 总结完全来自你每天的打卡、成就、总结、感悟——平时填得越认真，总结越有用。
  • 风险标签靠「近期投入」判断：某项目连续几天没绑定区块打卡，就会预警。
  • 与「周与双周对比」「学习进度」互补：总结看「这一周期发生了什么」，对比看「和上一周期差多少」。

五、常见问题

Q：提示「该区间还没有任何打卡记录」？

A：说明这段日期你没在对应天打卡（或日期选错）。先去那些天补打卡，总结才有内容。

Q：项目投入显示 0 但我在学？

A：今日看板里那块没「绑定科目」，或没标记完成。绑定科目并打卡，投入才会汇总进来。

周与双周对比 · 使用帮助

把相邻的两个周期（上周 vs 本周，或上双周 vs 本双周）并排拉出来，直观看清节奏变化——哪里进步了、哪里滑坡了。

一、入口

底部视图栏 📈 周 / 双周对比。

二、它比「周期总结」强在哪

  • 周期总结看「这一周期发生了什么」；
  • 对比看「这一周期相比上一周期差多少」——增量、回落一目了然。

三、怎么用

  1. 选对比粒度：周（7 天）或双周（14 天）。
  2. 系统自动取「上一周期」与「本周期」两组数据并排：
  • 核心完成率、专注时长等核心指标的前后对比；
  • 各项目投入的前后变化（哪些项目这周期多投了、哪些少了）；
  • 里程碑推进差异。
  1. 看红绿箭头：涨了绿、跌了红，快速定位需要关注的维度。
  2. 结合「周期总结」的「风险项目」一起读，制定下周策略。

四、要点

  • 对比依赖「周期总结」的聚合数据，所以同样要求你平时认真打卡、写总结。
  • 双周粒度更适合长线备考（考研/考公），能滤掉单周波动，看真实趋势。
  • 它是「计划—执行—复盘—调整」闭环里的「调整」依据。

五、常见问题

Q：对比数字和上期对不上？

A：对比取的是真实 days 数据聚合；若某天补打卡发生在对比之后，会反映进最新周期。

Q：为什么只有两周能比？

A：设计就是相邻周期横向比；更长时间跨度的趋势请看「数据分析」的 30 天折线/16 周热力图。

Q：项目投入对比里某项目消失了？

A：上周期没投入或没绑定科目时，该项目的对比项可能为空；正常。

旅行日程 · 使用帮助

一个和「每日打卡、周期排程」完全独立的行程模块。一日游、多日游都能按天排，还能把某件事「规划」进具体日期的看板，让旅行和日常打卡真正打通。

一、入口

底部视图栏 ✈️ 旅行日程。

二、添加行程的两种方式

  • ＋ 新建行程：手动逐步填标题、每天日期与事项（时间/地点/备注/类型）。
  • 📥 导入行程：批量载入现成 .json（自己导出的、朋友分享的、或仓库示例）。详细格式与字段见 旅行日程导入帮助.md。
两种方式的区别：新建是手填，导入是离线批量载入（无需配 AI、无需联网）。导入只追加行程，不替换你已有的看板数据。

三、行程里有什么

每条行程 = 标题 + 若干「天」，每天有若干「事项」：

  • 起止时间 s/e、事项标题、地点 📍、备注、类型标签。

四、导入之后能做什么

每条行程卡片上可：

  • 展开/折叠：看每天安排。
  • ⏫ 置顶：常用行程顶到最前。
  • 编辑：改标题/日期/事项（同新建编辑器）。
  • 删除：只删这一条，不影响别的。
  • ⏰ 规划 / 📅 整日规划 / 📅 整行程：把行程里的某件事、某一天、或整段行程，落进具体日期的看板当「生活」类自定义块（与常驻计划分离，只当天生效；冲突自动顺延）。这就是「旅行」和「日常」打通的地方。

五、常见问题

Q：导入后在今日看板看不到？

A：行程在「✈️ 旅行日程」里；要落到某天看板，用卡片上的「规划」按钮选日期。

Q：拍照识别的行程在哪？

A：拍照识别（见「智能导入」）的结果确认后也会落进这里，与导入/新建的行程并存。

Q：重复导入同一文件会怎样？

A：id 相同会自动改名变成两条；想避免先删旧的。详见导入帮助文档。

旅行日程 · 导入行程 使用帮助

本文档详细介绍 Dayboard（全天候成长看板） 里 ✈️ 旅行日程 → 📥 导入行程 功能怎么用。

一、这个功能解决什么

「旅行日程」是看板里一个和每日打卡、周期排程完全独立的模块，专门放你的出游行程（一日游、多日游都行）。

添加行程原本只有「＋ 新建行程」一条路——得一条条手填日期和事项，行程多的时候很累。

「📥 导入行程」就是给你一条批量捷径：手边有一份行程 .json（自己导出的、朋友分享的、或仓库里的示例），点一下就整批进看板，不用再手动敲。

---

二、入口在哪里

  1. 打开看板（双击 index.html）。
  2. 在底部视图栏切到 ✈️ 旅行日程。
  3. 顶部工具栏有两个按钮：
  • ＋ 新建行程：手动逐步填写。
  • 📥 导入行程：本文档主角，批量载入 .json。
即使是第一次进、列表还是空的，空状态提示里也带着这两个按钮，入口一样。

---

三、三步用法

  1. 准备好文件：一份行程 .json（格式见第四节，仓库里的 demos/travel-chengdu-demo.json 可直接试）。
  2. 点「📥 导入行程」 → 在弹出的文件选择框里选中那个 .json。
  3. 等提示：右下角弹出「已导入 N 条行程」，行程立刻出现在列表里，可展开查看每天的安排。

就这么简单。导入是增量追加，不会动你已有的打卡、排程和其他数据。

四、支持的文件格式（自动识别，三种都行）

importTripFile 会按下面顺序自动判断文件属于哪种，无需你选格式：

格式一：整份备份 JSON（含 trips 数组）

就是「数据 → 导出备份」生成的那种全量文件，或仓库示例那样的文件。

导入时只取其中的 trips 部分，其余（打卡、排程等）忽略——所以你可以用一份完整备份来"只加行程"，不用担心覆盖当前看板。

例：demos/travel-chengdu-demo.json（一份完整备份，内含 7 条成都周边行程）。

格式二：纯行程数组

文件本身就是一个数组，每个元素是一条行程：

[
  {
    "id": "trip-a",
    "title": "周末周边游",
    "days": [ { "label": "Day1", "items": [ { "s": "09:00", "e": "12:00", "t": "爬山", "place": "某山" } ] } ]
  },
  {
    "id": "trip-b",
    "title": "小长假三日游",
    "days": [ { "label": "Day1", "items": [] }, { "label": "Day2", "items": [] }, { "label": "Day3", "items": [] } ]
  }
]

格式三：单条行程对象

文件本身就是一个行程对象（带 id / title / days）：

{
  "id": "trip-alone",
  "title": "一个人的 city walk",
  "days": [
    {
      "key": "2026-10-02",
      "label": "Day1 · 老城区",
      "items": [
        { "s": "10:00", "e": "11:30", "t": "咖啡馆", "place": "XX 路", "note": "靠窗位", "type": "休闲" },
        { "s": "14:00", "e": "17:00", "t": "博物馆", "place": "市博", "note": "提前预约", "type": "文化" }
      ]
    }
  ]
}

---

五、字段详解

一条行程（normalizeTrip 归一化后）的结构：

字段说明是否必填
id行程唯一标识。导入时若与已有行程 id 重复，会自动改名（加时间戳/随机数）避免冲突。建议起有意义的短 id。建议有
title行程标题，显示在卡片头部。建议有
source来源标记，photo=拍照识别 / json=导入 / 留空=手动。仅影响卡片上的小徽章。否
days按天的数组，每条行程至少 1 天。是

days 里每一天：

字段说明
key日期 YYYY-MM-DD。可留空，留空时按 label 显示、规划时不绑定具体日期。
label当天显示名，如「Day1 · 都江堰」「10 月 2 日」。
items当天事项数组，可空（当天无具体安排）。

items 里每件事：

字段说明
s / e起 / 止时间 HH:MM，如 "09:00" / "12:00"。可只填 s。
t事项标题，如「爬青城山」。
place地点，渲染时带 📍 徽标。
note备注。
type类型标签，如「交通」「餐饮」「景点」「休闲」。
即使文件字段不全（缺 key、缺 place 等），normalizeTrip 也会补全默认值，不会导入失败——放心用。

六、与「导入备份」的关键区别（重要）

📥 导入行程（旅行日程内）导入备份（数据面板内）
入口✈️ 旅行日程 → 📥 导入行程底部「数据」→ 导入备份
作用范围只追加行程到 state.trips整份替换当前看板（打卡、排程、行程、设置全换）
对其他数据不触碰你已有的打卡 / 排程 / 其他行程全部被文件内容覆盖
适用只想加几趟旅行，保留现有看板想整体切换到某个示例场景（如专心考研）
冲突处理id 重复自动改名，可多次导入直接覆盖，无合并
一句话：只想加行程 → 用「导入行程」；想整个看板换成别的状态 → 用「导入备份」。

---

七、导入之后能干什么

行程进列表后，每条卡片上都能：

  • 展开 / 折叠：点标题或 ▸ 箭头。
  • ⏫ 置顶：把常用行程顶到最前。
  • 编辑：改标题、日期、事项（和「＋ 新建行程」同一个编辑器）。
  • 删除：删掉某条（只删这一条，不影响别的）。
  • ⏰ 规划 / 📅 整日规划 / 📅 整行程：把行程里的某件事、某一天、或整段行程，落进具体日期的看板当「生活」类自定义块（与常驻计划分离，只当天生效；冲突时自动顺延）。这是"旅行"和"日常打卡"真正打通的地方。

八、常见问题

Q：导入后怎么在今日看板看不到？

A：行程在「✈️ 旅行日程」模块里，不在「📋 今日看板」。要落到某天看板，用卡片上的「规划」按钮选日期即可。

Q：导入同一个人发了两次的文件，会重复吗？

A：如果 id 相同会自动改名，变成两条（id 不同但内容相同）；若想避免，先删掉旧的那条再导入，或让对方改 id。

Q：导入错了 / 导入了不想留的？

A：逐条点「删除」即可，不影响其他数据和打卡。

Q：文件格式不对会怎样？

A：右下角提示「导入失败：…」，看板不变，不会留下半截数据。

Q：能用拍照识别代替吗？

A：能。「📋 今日看板 → AI 规划 → ✈️ 旅游行程」拍照/选图识别，结果会先确认再落库（需先在设置里配 AI 模型）。导入行程则是纯本地、无需联网、无需配模型的离线方式。

九、用示例快速体验

仓库里的 demos/travel-chengdu-demo.json 是一份完整备份，内含 7 条成都周边行程（4 条一日游 + 3 条多日游）。

方式 A（只加行程，推荐）

进入「✈️ 旅行日程」→ 点「📥 导入行程」→ 选 demos/travel-chengdu-demo.json → 7 条行程即时出现，你原本的看板原封不动。

方式 B（整体切换成示例状态）

进入「数据」→「导入备份」→ 选同一文件 → 整个看板变成成都周边旅游示例（打卡/排程也一并替换，五个示例互相独立）。

两种方式用的同一个文件，区别只在入口——这正是第六节那张表的含义。

冥想舱 · 使用帮助

一块完全离线的「安静角落」：实时合成的环境音场 + 4-2-6 呼吸节律引导，帮你从紧绷里抽离几分钟。无需联网、无音频文件下载。

一、入口

底部视图栏 🧘 冥想舱。

二、它有什么

  • 环境音场（实时合成）：雨声、海浪、白噪等氛围音由代码实时合成，不依赖任何外部音频资源，断网也能用。
  • 4-2-6 呼吸引导：吸气 4 秒、屏息 2 秒、呼气 6 秒的节律提示，跟着做即可放松。
  • 时长设定：自己定本次冥想几分钟，点开始。
  • 近 14 天记录：柱状图显示每天冥想分钟数。
  • 冥想明细：最近 40 条记录，含日期、所用音效图标、分钟数。

三、怎么用

  1. 选一种环境音（或默认），设本次时长（如 10 分钟）。
  2. 点开始，跟着 4-2-6 节律呼吸；结束自动记录。
  3. 常来——冥想分钟会进「数据分析」的冥想 KPI 与汇总，也计入徽章。
  4. 回看「冥想明细」观察自己的坚持节奏。

四、要点

  • 冥想记录存在当天 days[日期].meditation 里，和打卡同库，随备份带走。
  • 音场是合成的，不同浏览器音色略有差异，属正常。
  • 几分钟也有效：哪怕 3 分钟，记录都会留下，关键是「每天有一点」。

五、常见问题

Q：没声音？

A：首次需点「开始」解锁浏览器音频（和番茄钟同理）；之后正常。

Q：冥想和专注（番茄钟）重复吗？

A：不重复。冥想是放松/喘息，专注是干活；两者时长分别计入冥想/专注统计。

Q：想换音效？

A：在冥想舱里切换环境音类型即可，记录会记下你用的那一种。

倒计时 · 使用帮助

把「考研 / 考试 / 出发行程」等关键节点放在一眼能看到的地方，倒计时提醒你离目标还有多久。

一、入口

底部视图栏 ⏳ 倒计时。

二、它有什么

  • 一组倒计时卡片：每个卡片 = 一个关键日期（如「考研初试 2026-12-21」「成都出发 2026-10-02」）。
  • 实时显示「距今 N 天」，临近时更醒目。

三、怎么用

  1. 新建倒计时：填名称 + 目标日期（可附备注/分类）。
  2. 编辑 / 删除：随时调整或移除。
  3. 常来本视图看还差多少天，配合「旅行日程」的出发日、各考试的报名/考试日做整体时间感管理。

四、要点

  • 倒计时和「旅行日程」的出行日期、各项目的里程碑日期是互补的：里程碑管「进度到哪」，倒计时管「离deadline 还有多久」。
  • 数据存本地，随备份带走。

五、常见问题

Q：能不能和考试/旅行自动联动？

A：目前是独立维护的；你可以把旅行出发日、考试日手动建一条倒计时，和对应模块对齐即可。

Q：过了目标日期还会显示吗？

A：通常显示「已过期 / 0 天」，可删掉或留作纪念。

Q：倒计时能提醒我吗？

A：看板本身不弹系统通知；它提供常驻的「还剩几天」视觉提醒，配合你自己的日程习惯使用。

智能导入（拍照识别） · 使用帮助

把课表、排班表、考试大纲、旅行攻略的照片/截图，在端侧识别成可编辑的日程或结构化内容，一分钟变成看板——不用一条条手敲。

一、入口

  • 今日看板顶部「📷 智能导入日程」或侧栏「✨ 智能添加」；
  • 旅行模块里的「📋 去 AI 规划识别 → ✈️ 旅游行程」也走这套识别。

二、它能识别什么

  • 课表 / 排班表：识别成当天（或按星期）的时段区块。
  • 考试大纲 / 大纲：识别成结构化大纲（进「大纲编辑器」）。
  • 题目 / 题干：可进「错题本」的题干框。
  • 旅游攻略 / 行程单：识别成行程，落进「✈️ 旅行日程」。

三、怎么用（通用流程）

  1. 打开智能导入，拍照或选图（也支持粘贴文本）。
  2. 选识别类型（日程 / 大纲 / 题目 / 旅游行程）。
  3. 端侧先做 OCR 出文字，再「解析」成结构化行；可「🤖 用 AI 解析」提升准确率（需配模型）。
  4. 预览确认每行的时间/内容是否正确。
  5. 冲突策略（加入常驻计划或当日排布时）：
  • 顺延：后面的整体后移，保住不重叠；
  • 取消：冲突段直接移除；
  • 裁剪：只保留不重叠部分。
  1. 点「应用到当日排布 / 加入常驻计划」生效。

四、要点

  • OCR 在端侧完成，原图一般不离开本机；「🤖 用 AI 解析」那一步会把文字发给你配置的模型（见「设置」）。
  • 识别结果先确认再落库，不会悄悄覆盖你的排程。
  • 与「旅行日程·导入行程」互补：拍照识别适合「手头有图」，导入 .json 适合「手头有文件」。

五、常见问题

Q：识别错行了？

A：在预览里手动改时间/内容，或换「🤖 用 AI 解析」再试；确认无误再应用。

Q：没有 AI 模型能识别吗？

A：OCR 与基础解析可离线；「用 AI 解析」更准确但需先在「设置 → AI 模型设置」配好视觉模型。

Q：应用到当日后想反悔？

A：当天调整是增量的；可用「清除当日调整」或手动编辑区块还原，不影响常驻方案。

AI 增强 · 使用帮助

看板内置多项 AI 能力，帮你在「规划 / 周报 / 撰写 / 总结 / 识别」上省力。这些能力默认关闭，配好模型才启用——且文本只在你配置后发往你指定的接口。

一、入口

  • 通用入口：⚙ 设置 → AI 模型设置（先在这里填好，功能才亮）。
  • 各处触发：今日看板区块 ✍「AI 写」、学习进度「✒ AI 写」、项目「AI 周报」、「✨ 智能添加 / AI 规划」面板、「📷 智能导入」的「🤖 用 AI 解析」。

二、包含哪些能力

  • AI 规划排程：根据项目目标/附加提示，生成当日或阶段的时间排布建议，可采纳为待办或区块。
  • AI 项目周报：按各项目近期执行情况，自动生成周报草稿。
  • AI 辅助撰写：帮你起草总结、复盘、材料。
  • AI 写总结（块级/科目）：基于今日完成情况 + 你写的 goal/extra，生成该项目学习总结。
  • 拍照/选图识别（智能导入）：OCR 后可选「用 AI 解析」提升结构化准确率（见「智能导入」帮助）。

三、怎么用

  1. 去「⚙ 设置 → AI 模型设置」填：服务地址、模型名、（识别用）视觉模型、密钥。
  2. 回到对应模块，点 AI 按钮 → 等待返回 → 采纳/编辑。
  3. AI 规划的结果先确认再落库，不会静默覆盖。

四、要点（数据隐私）

  • 基础打卡与统计完全本地运行，不联网。
  • 仅当你主动配置模型后，相关文本（如总结上下文、识别文字）才会发送到你填写的接口地址——你控制发往哪里。
  • 没配模型时，所有 AI 按钮会提示「先去设置填好模型」。

五、常见问题

Q：点了 AI 没反应？

A：九成是没配模型或地址/密钥填错；去设置核对，测试连通后再试。

Q：AI 写的不准？

A：把科目 goal/extra 写具体、给规划更明确的约束，输出会更贴。

Q：我的数据会被看板作者拿走吗？

A：不会。看板是单文件离线应用，AI 调用只走向你配置的地址，作者拿不到。

设置 · 使用帮助

看板的基础偏好 + AI 模型开关都在这。改完即时生效，随备份带走。

一、入口

底部视图栏 ⚙ 设置（或顶部齿轮）。

二、基础设置

  • 主题 / 显示偏好：明暗、密度等（按版本提供）。
  • 默认专注时长等习惯项：如番茄钟「运行到本时段结束」的记忆。
  • 数据相关：导出/导入备份入口也常挂在这里或「数据」面板。

三、AI 模型设置（关键）

要让 AI 能力（规划/周报/撰写/写总结/拍照识别的 AI 解析）可用，需填：

  • 服务地址：你的模型 API 基址（如兼容 OpenAI 的 /v1 地址）。
  • 模型名：对话模型（如 qwen 系列等）。
  • 视觉模型（识别用）：做图片 OCR/结构化时用的多模态模型。
  • 密钥：对应服务的 API Key。

填好后 AI 按钮才生效；没填则提示「先去设置填好模型」。

四、要点（隐私）

  • 不填模型 = 纯离线：打卡、统计、冥想、导入行程全部本地跑，不出本机。
  • 填了模型后，相关文本只发往你写的地址——你掌控数据去向。
  • 设置本身存在本地，随「导出备份」带走；换设备记得也导一份。

五、常见问题

Q：AI 一直转圈/报错？

A：地址或模型名不对、密钥失效、或网络不通。先确认别家客户端能用同配置，再回来测。

Q：不想用 AI 了？

A：清空模型设置即可，看板退回完全离线模式，不影响任何已有数据。

Q：设置会丢吗？

A：存在本地；清浏览器缓存或换设备会丢，记得用「导出备份」一并保存。

数据备份与恢复 · 使用帮助

看板数据存在浏览器本地。用「导出备份 / 导入备份」把整个状态打包成 JSON，换设备、防丢失、体验示例都靠它。

一、入口

底部视图栏 数据（或「⚙ 设置」相关面板）→ 导出备份 / 导入备份。

二、导出备份

  • 点「导出备份」→ 下载一份 dailyboard-...json，包含整个看板状态：打卡 days、周期排程 schedules、项目/科目、行程 trips、倒计时、设置等。
  • 建议定期导出，当作存档；换电脑/清浏览器前务必导一份。

三、导入备份（整份替换！）

  • 点「导入备份」→ 选一份 JSON → 当前看板被文件整体替换（打卡、排程、行程、设置全换成文件里的）。
  • 仓库里的 5 份演示（demos/*.json）就是这种整份备份，逐个导入即可体验不同场景。
⚠️ 导入是整份替换，不是合并。导入前最好先导出当前状态留底；五个示例互相独立，逐个体验即可。

四、和「导入行程」的区别（重要）

  • 导入备份（数据面板）= 替换整个看板。
  • 📥 导入行程（旅行日程内，见「旅行日程导入帮助」）= 只追加行程，不动其他数据。
  • 只想加几趟旅行 → 用旅行模块的导入行程；想整体切换场景 → 用导入备份。

五、常见问题

Q：导入后想要回原来的？

A：如果导入前导出了备份，再「导入备份」选那份即可恢复；没导出则无法回退。

Q：换浏览器/设备数据没了？

A：本地存储不跨设备；用导出备份带走，到新设备导入备份恢复。

Q：导入提示失败？

A：文件不是合法备份 JSON，或结构损坏；换一份确认正常的文件。

错题本 · 使用帮助

备考（考研政治、考公、资格考等）的错题收集站：把做错的题结构化存下，按科目/考点归档，配合拍照识别题干，省去手抄。

一、入口

  • 相关模块里的「错题」入口（如学习进度/项目下的错题本）；
  • 「智能导入」识别到「题目 / 题干」时，文字会直接进错题本的题干框。

二、一条错题有什么

  • 题目 / 题干：可粘贴，或用「智能导入」拍照识别填入（见「智能导入」帮助）。
  • 科目 / 考点：归类用，便于按考点复习。
  • 我的答案 / 正确答案：对照记录。
  • 错因 / 笔记：为什么错、怎么记。
  • 状态：已掌握 / 待巩固等。

三、怎么用

  1. 录题：手动粘贴题干，或拍照识别自动填入题干框，再补答案与错因。
  2. 归类：选科目与考点，方便日后筛选。
  3. 复习：按科目/考点过滤，重做或回忆；标记「已掌握」移出待巩固。
  4. 与进度联动：错题可关联对应项目，复盘时一起看薄弱点。

四、要点

  • 错题本是备考向的辅助模块，和「学习进度·里程碑」互补：里程碑管「学到哪」，错题本管「哪里易错」。
  • 题干识别依赖「智能导入」的 OCR（端侧），AI 解析可提升准确率但需配模型。

五、常见问题

Q：拍照识别的题没进错题本？

A：识别类型要选「题目/题干」；若选成「大纲/日程」会进别的模块。确认类型再识别。

Q：错题能导出吗？

A：随整个看板「导出备份」一起带走（错题存在本地状态里）。

Q：错因怎么记最有用？

A：写「知识点盲区 / 审题失误 / 计算错」这类可行动原因，而不是只抄正确答案。
